
# Практическая работа № 1 — ТРПО

## Тема

HTML и базовая CSS-разметка.
Семантическая структура страницы.

## Описание

Создана адаптивная информационная страница
об основах веб-разработки.

На странице присутствуют:
- семантическая HTML-разметка;
- навигация по разделам;
- шесть карточек с данными;
- таблица;
- форма с проверкой введённых значений;
- изображения SVG;
- адаптивное оформление CSS.

## Используемые технологии

- HTML5
- CSS3
- Git

## Структура проекта

- index.html — основная страница;
- css/styles.css — стили;
- data/content.csv — исходные данные;
- data/navigation.json — пункты навигации;
- images/cover.svg — иллюстрация;
- images/logo.svg — изображение для шапки.

## Использование данных

Сведения из content.csv перенесены в карточки
и таблицу страницы.

Названия пунктов навигации и их целевые разделы
соответствуют navigation.json.

## Запуск

1. Открыть папку проекта в Visual Studio Code.
2. Открыть index.html через Live Server.
3. Проверить навигацию, форму и адаптивность.

Установка npm-пакетов не требуется.
